Privacy Policy

{{ content.companyName }} (“Kainazi”, “we”) publishes this policy for Kainazi Server Backup, a private utility used by the owner to automatically upload server backup files to the owner’s Google Drive account.

The application is not offered to the public. This page explains what Google user data it accesses, how that data is used, and how the owner can disconnect it. The Kainazi website is {{ content.siteUrl }}.

Google data we access

When the owner connects a Google account, Kainazi Server Backup accesses:

  • The Google account required to sign in and authorize the connection.
  • Google Drive, so the application can upload server backup files into that account.

That access is used only to authenticate the owner and to upload those backup files to the owner’s Google Drive.

How Google data is used

Google account and Google Drive data are used solely to upload server backup files to the owner’s Google Drive account.

The application does not sell, share, or use Google Drive data for advertising or any unrelated purpose. It does not use Google user data to build advertising profiles, and it does not transfer that data to advertisers or data brokers.

Limited use

Kainazi Server Backup’s use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Sharing

We do not sell Google user data and we do not share it with third parties for their own purposes. Backup files are stored in the owner’s Google Drive account and remain under that Google account’s controls. Google’s handling of the account is covered by Google’s terms and privacy policy.

Retention and deletion

Backup files stay in the owner’s Google Drive. The owner can delete them there at any time. The owner can also disconnect Kainazi Server Backup from the Google account under Google Account permissions (Google Account, Data and privacy, Third-party apps and services). Disconnecting stops further uploads that depend on that authorization.

Security

Access is limited to the Google account the owner authorizes and is used only for the backup upload described above.
